# منصة رشيد التعليمية

مشروع مستقل لإدارة المؤسسات التعليمية والمجمعات والفروع والمدارس.

- الموقع الرئيسي: `index.html`
- لوحة المالك: `admin/platform-dashboard.html`
- تطبيق PWA مستقل: `manifest.webmanifest` و`sw.js`

## رابط GitHub Pages المقترح
`https://samysuliman.github.io/rasheed-platform/`


## ملاحظة تقنية
بعض أسماء الجداول البرمجية القديمة ما زالت مستخدمة داخليًا للحفاظ على توافق قاعدة البيانات، ولا تمثل هوية المشروع أو واجهته العامة.


## إصدار التنظيف الأول
تم تنظيف هوية منصة رشيد التعليمية وإزالة العبارات المرئية الخاصة بالمشروع الآخر، مع الحفاظ على النواة البرمجية والتوافق الحالي مع قاعدة البيانات.
