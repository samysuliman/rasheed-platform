# منصة رشيد التعليمية

مشروع مستقل لإدارة المؤسسات التعليمية والمجمعات والفروع والمدارس، بهوية منفصلة عن أكاديمية رشيد والموقع المهني.

## التشغيل

- الصفحة الرئيسية: `index.html`
- تسجيل الدخول: `login.html`
- لوحة المالك: `admin/platform-dashboard.html`
- تطبيق PWA: `manifest.webmanifest` و`sw.js`
- رابط الموقع: `https://samysuliman.github.io/rasheed-platform/`

## الهيكل

```text
admin/      لوحات الإدارة والمالك
teacher/    بوابة المعلم
student/    بوابة الطالب
parent/     بوابة ولي الأمر
assets/     الأنماط والبرمجة والصور والشعارات والأيقونات
```

## الهوية والنطاق

المشروع مخصص لمنصة رشيد التعليمية بوصفها نظامًا عامًا لإدارة المؤسسات التعليمية. بعض أسماء الجداول والمفاتيح القديمة باقية داخليًا مؤقتًا للمحافظة على التوافق مع قاعدة البيانات، ولا تظهر في الهوية العامة.

## إصدار التنظيف المعماري v3

- إزالة الأصول والملفات التجريبية غير المستخدمة.
- إزالة النسخ المكررة من الصور والصفحات والبرمجة.
- تثبيت مجلدات الأصول الحالية دون تغيير المسارات العاملة.
- تحديث إصدار ذاكرة التخزين المؤقت لتطبيق PWA.
- الحفاظ على الصفحات والوظائف المرتبطة بقاعدة البيانات دون إعادة تسمية داخلية خطرة.
